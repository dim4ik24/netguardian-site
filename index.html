ПРОГРАМНІ
МОЖЛИВОСТІ

Комплексний аналіз від фізичного рівня до додатків з автоматичним виправленням

01
⚡
Multi-Layer Diagnostics
Одночасно перевіряє зв'язок до роутера, провайдера і Google. Якщо тільки роутер лагає — проблема у вас вдома. Якщо далі — вже провайдер. 230+ правил від L1 до L7.
02
🧠
Hybrid AI Engine
Аналізує дані мережі і пояснює проблему звичайною мовою. Є інтернет — питає Google Gemini. Немає — відповідає з власної бази знань. Завжди дає відповідь. Gemini → KB → Pi AI fallback.
03
🔧
Auto-Healing
Знайшла проблему — виправила сама, без участі користувача. Очищає DNS, оновлює IP-адресу, відновлює мережеву карту, вимикає живлення роутера. 35+ автоматичних сценаріїв.
04
📡
DNS Benchmark
Перевіряє швидкість 12+ DNS-серверів і встановлює найшвидший. Повільний DNS — одна з найчастіших причин «повільного інтернету», хоча швидкість нормальна. Cloudflare 1.1.1.1 / Google 8.8.8.8 / DoH.
05
🎮
Game Mode
Під час гри зупиняє фонові оновлення Windows і торренти, що «крадуть» канал. Налаштовує пріоритет ігрового трафіку. QoS, MTU tuning, TCP Nagle off.
06
🛡️
LAN Security
Показує всі пристрої у вашій мережі. Якщо з'явився чужий — сповіщення одразу в Telegram. Визначає виробника за MAC-адресою. ARP-скан, OUI lookup, whitelist.
07
📈
Internet Weather
Записує якість інтернету кожну хвилину і будує «погоду» за тиждень. Видно коли провайдер найгірший і чи виконує він свої обіцянки щодо швидкості. SLA, heatmap, anomaly detection.
08
🌐
Auto-VPN
Керує VPN-підключенням і захищає від «витоку» трафіку. Якщо VPN несподівано відключається — блокує інтернет до відновлення. Radmin/OpenVPN/WireGuard, Kill Switch.
09
⚡
Voltage Guardian
Слідкує за напругою в розетці роутера. Якщо напруга впала або стрибнула — автоматично відключає живлення і вмикає знову. Захищає від пошкодження обладнання. Tapo P110, V<190V або V>250V → auto power-off.

Алгоритм Watchdog
01
Безперервне спостереження
Pi кожні 30 секунд перевіряє чи доступний інтернет — надсилає сигнал на Google і Cloudflare. Якщо відповідь прийшла — все добре. Паралельно передає дані на основний ПК.
ping_interval = 30s | hosts = [8.8.8.8, 1.1.1.1]
02
Виявлення збою
Якщо 10 перевірок поспіль не отримали відповіді — це вже 5 хвилин без інтернету. Система вирішує що роутер завис і треба вжити заходів.
if failed_pings >= 10: trigger_power_off()
03
Вимкнення живлення через Tapo
Pi надсилає команду розетці Tapo по локальній мережі — без інтернету. Tapo відключає живлення роутера. Після цього роутер потрібно ввімкнути вручну або через команду в Telegram.
POST /api/device {"state":"off"} ← тільки вимкнення
04
Сповіщення в Telegram
Одразу після вимкнення — повідомлення в Telegram з інформацією скільки часу роутер не відповідав. Ви дізнаєтесь про це де б не були.
telegram.send("⚡ Power OFF | downtime: {t}s")

02
☁️
Хмарний бекенд
Перенесення збору метрик на хмарний сервер для перегляду статистики мережі з будь-якого пристрою через браузер, незалежно від стану домашнього ПК.AWS / GCP + веб-дашборд
03
🧬
ML замість правил
Заміна 230+ фіксованих правил діагностики на ML-модель, що навчається на реальних даних конкретної мережі та адаптується під поведінку кожного користувача.scikit-learn / LSTM · anomaly detection
04
🔐
Шифрування MQTT
Поточна передача даних між Pi і ПК через публічний HiveMQ-брокер не захищена. Впровадження TLS та автентифікації закриє цю вразливість.TLS 1.3 + X.509 certificates · private broker
05
🌐
Підтримка IPv6
Система повністю побудована на IPv4. З поступовим переходом інтернету на IPv6 це стає критичним обмеженням для широкого застосування.Dual-stack IPv4/IPv6 · ICMPv6 діагностика
06
🔌
Інтеграція з роутером
Пряма інтеграція з API роутера дозволить перезапускати сервіси, змінювати DNS і керувати QoS без фізичного вимкнення живлення через Tapo.OpenWrt / DD-WRT REST API · SSH
07
📊
Автозвіти для провайдера
Автоматична генерація щомісячного PDF-звіту з графіками SLA, кількістю інцидентів та хронологією збоїв — для офіційних претензій до провайдера.ReportLab PDF · підписані timestamp-дані
08
🖥️
Windows Service
Встановлення як системна служба Windows забезпечить автоматичний запуск при старті ОС, роботу у фоні без графічного вікна та відновлення після збоїв.pywin32 · NSSM · Windows Task Scheduler
09
🍓
Кілька Pi-агентів
Підтримка мережі з кількох Pi-агентів у різних частинах будинку чи офісу для точнішої локалізації проблем і моніторингу великих інфраструктур.MQTT topics per agent · агрегація метрик
10
🌍
Підтримка кількох мереж
Централізований моніторинг кількох мереж одночасно — для офісів, коворкінгів або провайдерів, що обслуговують кілька об'єктів.Multi-tenant архітектура · роль-базована авторизація
